PREREQUISITES THIS CHART DID NOT CREATE (and never will):
Two Secrets must exist in the namespace BEFORE install; they come from
the Ansible vault (ADR-0002/0004), never from Helm — values files are
plaintext in git and release manifests are readable in-cluster, so
secrets do not pass through either:

  VP=$(ansible-vault view ansible/group_vars/all/vault.yaml)
  kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.existingSecret }} \
    --from-literal=SECRET_KEY="$(echo "$VP" | grep vault_flask_secret_key | cut -d'"' -f2)" \
    --from-literal=POSTGRES_PASSWORD="$(echo "$VP" | grep vault_postgres_password | cut -d'"' -f2)"
  kubectl -n {{ .Release.Namespace }} create secret docker-registry ghcr-pull \
    --docker-server=ghcr.io --docker-username=<github-user> \
    --docker-password="$(echo "$VP" | grep vault_ghcr_read_token | cut -d'"' -f2)"

If pods sit in CreateContainerConfigError or ImagePullBackOff, a missing
Secret is the first thing to check.
